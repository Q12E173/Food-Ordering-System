# Food Ordering System

A web-based food ordering system developed as a university group project.

The system was designed to streamline the food ordering process by providing digital menu browsing, cart management, order processing, and administrative management functions.

## Key Features

### Customer
- User registration and login
- Browse food menu by category
- Add food items to cart
- Increase or decrease food quantities
- View cart and total price
- Confirm and place orders
- Generate and download order paper
- Logout

### Administrator
- Admin authentication
- Dashboard with user, order, and earnings information
- View and manage customer orders
- Update order status
- Delete orders
- Print completed order receipts
- Add new dishes
- Edit and delete existing dishes
- Upload food images
- View menu by food category
- View daily and yearly earnings
- Reset administrator password
- Logout

## Technologies Used

- HTML5
- CSS3
- JavaScript
- PHP
- MySQL
- XAMPP / Apache

## Project Highlights

- Developed a database-driven web application for restaurant food ordering.
- Implemented customer and administrator functionalities with role-based access.
- Implemented CRUD operations for food menu and order management.
- Integrated PHP with MySQL for storing and retrieving user, food, and order data.
- Designed interactive interfaces for both customers and administrators.
- Implemented input validation and authentication for user and administrator access.
- Participated in system design, coding, testing, and debugging as part of a four-member team.

## Database

- Database Name: `food`
- Database File: `2A_FoodOrderingSystem_Database.txt`

## Local Setup

1. Import `2A_FoodOrderingSystem_Database.txt` into MySQL.
2. Place the project folder inside the XAMPP `htdocs` directory.
3. Start Apache and MySQL using XAMPP.
4. Open the system in a web browser:

```text
http://localhost/2A_FoodOrderingSystem/main.html
````
